# Changelog

## 1.3.0

### Added

- Static combinational `Bits.GetByteBit` for byte-to-logic bit selection without
  scheduled calls, with exhaustive byte and bit-position tests.

### Compatibility

- Existing scheduled integer helper APIs and timing contracts are unchanged.
- No new package dependencies.

## 1.2.1

### Added

- Publish package discovery metadata, the README, the changelog, and the MIT
  license with this version.

### Compatibility

- No component API or dependency changes from 1.2.0.

## 1.2.0

- Foundational bits, arrays, strings, conversions, formatting, timing, and
  simulation/test diagnostics for the Livt standard library.
